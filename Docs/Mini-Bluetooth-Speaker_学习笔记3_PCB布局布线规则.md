## 一、PCB布局规则

### 1.1 布局五梯队优先级（核心方法论）

PCB布局不是随便摆，有严格的优先级顺序。核心原则：**锚点先定 → 关键芯片居中 → 敏感模块优先 → 大电流路径 → 小元件填空**。

| 梯队 | 摆什么 | 为什么这个顺序 |
|:---|:---|:---|
| **第1梯队** | 接口锚点（USB/电池/TF/AUX/耳机/喇叭/按键） | 必须贴板边，位置被外壳结构锁死，是所有内部电路的端点 |
| **第2梯队** | 核心芯片（AC6965A主控 + LTK5128D功放） | 芯片是信号心脏，外围元件围绕它转，位置决定走线长度 |
| **第3梯队** | 射频天线 + π型匹配网络 | 2.4GHz信号最娇贵，位置一定就要锁死净空区 |
| **第4梯队** | 电源路径（充电IC/切换/LDO/大电容） | 大电流路径要粗且短，大元件先摆 |
| **第5梯队** | 被动元件（去耦电容/晶振周边/ADC电阻） | 体积小数量多，紧贴对应芯片引脚填空 |

### 1.2 各模块布局要点

#### 接口锚点（第1梯队）

| 接口 | 布局位置 | 原因 |
|:---|:---|:---|
| USB座 | 顶边 | 充电/数据输入，用户可触及 |
| 电池座 | 顶边USB旁 | 充电路径最短 |
| TF卡座 | 右边 | 插拔方向朝外 |
| AUX座 | 底边 | 音频输入 |
| 耳机座 | 底边AUX旁 | 音频输出 |
| 喇叭座 | 左边 | 靠近功放，大电流走线短 |
| 按键 | 右边/底边 | 手指操作习惯 |

**铁律**：接口必须贴板边，开口朝外，方向对齐外壳开孔。

#### 核心芯片（第2梯队）

| 芯片 | 位置 | 布局逻辑 |
|:---|:---|:---|
| AC6965A | 板子中央偏右 | 靠近TF卡（右）和天线（右上），SD信号和射频走线短 |
| LTK5128D | 主控左侧，靠近喇叭座 | DAC输出→功放→喇叭形成顺畅信号流 |

**信号流向原则**：
```
蓝牙信号 → AC6965A → DAC输出 → LTK5128D → 喇叭
  天线      主控       音频链路    功放      输出
（右上）  （中央）    （短走线）  （左侧）  （左边）
```
信号从右上（天线）进来，经过中央主控，到左侧功放，再到左边喇叭——形成一条顺畅的信号流，不走回头路。

#### 射频天线（第3梯队，最敏感）

- 天线在**板角**（右上角最佳），三面净空
- 净空区内**禁止**：地铜、走线、元件、过孔
- π型匹配网络**紧贴**天线馈点
- 50Ω共面波导从BT_RF引脚到天线，全程等宽

#### 电源路径（第4梯队，大电流）

| 模块 | 位置 | 原因 |
|:---|:---|:---|
| 充电IC（LGS4056HDA） | 靠近USB和电池（顶边） | 充电电流路径最短 |
| 电源切换（LM66100/CH213K） | 充电IC旁 | 输入端靠近电源入口 |
| LDO（ME6211） | 靠近主控VCC引脚 | 3.3V供电走线短纹波小 |
| 大电解电容 | 电源入口处 | 储能滤波靠近源头 |

**电源布局口诀**：大电流走直线，电容紧靠引脚，地平面要完整。

#### 被动元件（第5梯队，填空）

摆放优先级：
1. 晶振 + 负载电容 → 紧贴主控OSC引脚，走线最短
2. 去耦电容 → 每个IC的VCC引脚旁边，越近越好
3. RC滤波网络 → 靠近信号输入端
4. 普通电阻/小电容 → 最后填空隙

### 1.3 布局检查清单

- [ ] 所有接口贴板边，方向正确
- [ ] 主控和功放相对位置形成顺畅信号流
- [ ] 天线在板角，净空区无任何导体
- [ ] 电源大元件靠近电源入口
- [ ] 晶振紧贴主控OSC引脚
- [ ] 去耦电容紧贴各IC电源引脚
- [ ] 元件间距满足制造要求（≥0.2mm）

## 二、PCB布线规则

### 2.1 走线分类与规则总览

本项目所有走线按信号类型分为5类，每类规则不同：

| 走线类型 | 本项目实例 | 阻抗要求 | 线宽 | 关键规则 |
|:---|:---|:---|:---|:---|
| **射频走线** | BT_RF→天线 | 50Ω单端 | 按阻抗计算器 | 共面波导，全程等宽 |
| **差分对走线** | USB D+/D- | 90Ω差分 | 按阻抗计算器 | 等长、紧耦合、平行 |
| **单端信号** | TX/RX、晶振、SD卡、ADC按键 | 无严格要求 | 0.2~0.25mm | 短直，少拐角 |
| **音频走线** | DACL/DACR→功放 | 无严格要求 | 0.2~0.3mm | 短走线，远离数字噪声 |
| **电源走线** | VCC-5V/VCC33/VCC-MCU | 无 | 0.4~1.0mm按电流 | 粗线，电容就近 |
| **大电流输出** | 功放→喇叭（BTL） | 无 | ≥0.4mm | 粗且短，对称 |

### 2.2 射频走线（50Ω共面波导）

#### 原理
50Ω不是"接一个50Ω电阻"，而是PCB走线本身的特性阻抗=50Ω。蓝牙芯片BT_RF引脚、天线、走线三者必须都50Ω，信号传输效率最高。

#### 共面波导结构
```
GND │ 信号线 │ GND   ← 全在顶层

三个参数控制阻抗：
  W（线宽）↑ → 阻抗↓
  S（间距）↑ → 阻抗↑
  H（板厚）↑ → 阻抗↑
```

#### 布线规则
- BT_RF → C3(2.7pF) → π型匹配 → 天线，全程50Ω共面波导
- 走线**全程等宽**，不能忽粗忽细
- 两侧每1~2mm打GND过孔（地过孔缝合）
- 正下方必须是完整GND平面
- **复刻策略**：照抄原版走线宽度和间距，不要自己改

#### 阻抗计算
- 1.6mm双层板，FR4材质
- 用嘉立创EDA阻抗计算器：输入板厚1.6mm、铜厚1oz、目标50Ω，获取线宽和间距
- 注意：0.2mm介质和1.6mm介质的50Ω线宽完全不同

### 2.3 USB差分对走线（90Ω）

#### 为什么USB要差分
USB D+/D-是同一路信号的正反相版本，同时传输同一份数据。差分抗干扰原理：共模噪声同时影响两根线，接收端一减就抵消。

#### 5条铁律

| # | 铁律 | 原因 |
|:---|:---|:---|
| 1 | 阻抗严格90Ω | USB 2.0标准，失配会反射畸变 |
| 2 | 两根线必须等长 | 长度差导致skew，接收端误判 |
| 3 | 全程紧耦合平行走 | 间距恒定，耦合均匀，抗干扰才有效 |
| 4 | 正下方完整GND平面 | 差分信号需要GND回流路径 |
| 5 | 尽量少用过孔 | 过孔破坏阻抗连续性 |

#### 本项目实际情况
- AC6965A的USB是USB 2.0 Full Speed (12Mbps)，速度不高
- USB走线极短（< 20mm），阻抗轻微失配影响很小
- **可以用嘉立创EDA默认差分对规则**，不必须精确算90Ω
- 但必须用差分布线工具走，不要手动画两根线

#### 等长控制标准
- USB 2.0 High Speed (480Mbps)：长度差 ≤ 5mil (0.127mm)
- USB 2.0 Full Speed (12Mbps)：可放宽到 ≤ 25~50mil

#### 嘉立创EDA操作
1. 在规则管理界面将USBDM和USBDP绑定为差分对
2. 确认默认规则线宽≥0.2mm，间距0.2mm左右
3. 选中差分对 → 右键 → 差分对布线（EDA自动保证平行、等距、同步拐弯）
4. 如需等长：设计 → 差分对等长（自动蛇形绕线）

### 2.4 晶振走线（单端，非差分）

#### 重要认知：晶振不是差分走线

| 对比 | 差分对 | 晶振（单端） |
|:---|:---|:---|
| 信号定义 | 同一路信号的正反相 | 两个独立单端信号 |
| 网络命名 | `_P`/`_N`成对 | BT_OSCO / BT_OSCI（独立命名） |
| 走线要求 | 紧耦合、等长 | 各走各的，不要求等长 |

#### 晶振工作原理
```
AC6965A内部反相放大器 ←→ 24MHz晶振
  BT_OSCO = 输出，驱动晶振
  BT_OSCI = 输入，接收晶振反馈
晶振是无源谐振器，形成反馈回路
```

#### 布线规则
- BT_OSCO和BT_OSCI是**两条独立单端信号**，各参考GND
- 走线**越短越直越好**，不需要精确等长
- 不必要的蛇形绕线可以去掉
- 晶振周围有GND铜皮环绕（地环保护），减少EMI
- 负载电容（12pF）紧贴晶振引脚

### 2.5 UART串口走线（TX/RX，单端）

#### 为什么TX/RX不是差分
TX和RX是**两个独立通道**，TX发数据、RX收数据，各传各的。不是同一信号的正反相，各自以GND为参考。

| 对比 | 差分对（USB D+/D-） | UART（TX/RX） |
|:---|:---|:---|
| 信号关系 | 同一路信号的正反，同时传 | 两条独立通道，各传各的 |
| 走线要求 | 紧耦合、等长、平行 | 普通单端，短直即可 |
| 速度 | 12Mbps+ | 115200bps（低速） |

#### 布线规则
- 普通单端走线，线宽0.2~0.25mm
- 短直走线，少拐角
- 不需要等长、不需要紧耦合

### 2.6 音频走线

#### DAC输出→功放
```
DACL → C14(68nF隔直) → R18(47kΩ输入电阻) → LTK5128D IN-
DACR → C16(68nF隔直) → R20(47kΩ输入电阻) → LTK5128D
```
- 走线短，远离数字噪声源（晶振、USB、SD卡时钟）
- 线宽0.2~0.3mm
- DACL/DACR是两条独立单端，不是差分

#### 功放输出→喇叭（BTL）
- OUTP/OUTN是大电流BTL输出，走线≥0.4mm
- 两根线尽量对称、等长（减少BTL不平衡）
- 走线尽量短，减少EMI辐射
- D类功放有520kHz开关频率，注意EMI

### 2.7 电源走线

| 电源网络 | 电流大小 | 线宽建议 | 布线要点 |
|:---|:---|:---|:---|
| VCC-5V（USB输入） | ~1A（充电） | ≥0.6mm | 粗线，从USB到充电IC直线 |
| VBAT（电池） | ~1A | ≥0.6mm | 粗线，电池到切换IC |
| VCC-MCU（功放电源） | ~0.5A | ≥0.4mm | 粗线，大电容储能 |
| VCC33（3.3V） | ~0.3A | ≥0.4mm | LDO输出到各IC |
| GND | 最大 | 尽量粗/铺铜 | 完整地平面 |

**电源布线口诀**：
- 大电流走直线，不绕弯
- 滤波电容紧靠IC电源引脚（先过大电容再小电容）
- 电源走线与信号走线分层/分区域，避免交叉

### 2.8 地平面与铺铜处理

#### 核心原则：完整GND平面
- 双层板：顶层走信号，底层尽量整片铺GND
- 底层GND铺铜尽量不被走线割裂
- 射频走线正下方必须是完整GND

#### 关键区域地处理

| 区域 | 地处理要求 |
|:---|:---|
| 射频区 | 走线两侧GND铜皮完整，每1~2mm打过孔缝合到底层GND |
| 天线净空区 | **禁止铺铜**，三面净空 |
| 功放底部 | 大面积GND铺铜散热（ESOP-8散热焊盘） |
| 晶振周围 | GND铜皮环绕（地环保护） |
| 电源区 | GND铺铜完整，大电容地端就近回流 |

#### 过孔缝合（GND Via Stitching）
- 顶层GND铜皮和底层GND铺铜之间，用大量GND过孔连接
- 射频区每1~2mm打一个
- 其他区域均匀分布，间距2~5mm

### 2.9 过孔规则

| 场景 | 过孔使用建议 |
|:---|:---|
| USB差分对 | 尽量不打，必须打时D+和D-对称打一对 |
| 射频走线 | 尽量不打，保持同一层 |
| 电源走线 | 可以打，过孔承载电流约0.5~1A/孔，大电流多打几个并联 |
| GND缝合 | 大量使用，连接两层GND |
| 普通信号 | 可以打，但少打为好 |

**过孔规格**：外径0.3mm，内径0.15mm（嘉立创默认免费规格）

## 三、差分对 vs 单端信号判断方法

### 3.1 判断四维度

| 维度 | 单端走线 | 差分布线 |
|:---|:---|:---|
| 信号定义 | 一根信号 + GND参考 | 两根线互相参考 |
| 网络命名 | 单一名字（如BT_OSCO） | 成对出现（如USB_D+/USB_D-） |
| EDA标识 | 普通走线 | 差分对绑定，特殊高亮 |
| 走线特征 | 各走各的 | 紧耦合、等长、平行 |

### 3.2 嘉立创EDA查差分对
- **方法A**：选中走线 → 属性面板 → 看网络名是否成对（_P/_N）
- **方法B**：设计 → 差分对 → 查看已定义的差分对列表

### 3.3 本项目信号分类汇总

| 信号 | 是否差分 | 走线要求 |
|:---|:---|:---|
| USB D+ / D- | ✅ 是 | 90Ω差分，等长紧耦合 |
| UART TX / RX | ❌ 否 | 普通单端，短直 |
| BT_OSCO / BT_OSCI | ❌ 否 | 两条单端，尽量短直 |
| DACL / DACR | ❌ 否 | 两条独立单端 |
| 喇叭 OUTP / OUTN | ❌ 否（BTL输出） | 大电流粗线，不需要差分布线 |

**记法**：差分对 = 同一路信号的"正"和"负"同时传，命名一定有 `_P/_N` 或 `_+/-` 后缀。

## 五、本次会话核心知识点沉淀

### 5.1 布局方法论
- **五梯队优先级**：接口锚点 → 核心芯片 → 射频天线 → 电源路径 → 被动元件
- **信号流向原则**：信号从输入到输出形成顺畅流，不走回头路
- **接口贴边铁律**：所有需要插拔的元件必须贴板边，开口朝外

### 5.2 走线分类认知
- **差分对**：同一信号的正反相，紧耦合等长平行（本项目仅USB D+/D-）
- **单端信号**：一根线+GND参考，各走各的（晶振、UART、音频、ADC按键）
- **BTL输出**：功放喇叭输出，大电流粗线，不是差分

### 5.3 阻抗三要素
| 信号类型 | 阻抗要求 | 本项目是否必须精确 |
|:---|:---|:---|
| 射频（BT_RF） | 50Ω单端 | 是，照抄原版走线参数 |
| USB差分 | 90Ω差分 | 否，12Mbps低速短走线可宽松 |
| 其他信号 | 无严格要求 | 否 |

### 5.4 地平面核心
- 完整GND是信号质量和EMI的基础
- 射频区下方必须完整，天线区必须净空
- 双层板：顶层走信号，底层铺GND，过孔缝合
