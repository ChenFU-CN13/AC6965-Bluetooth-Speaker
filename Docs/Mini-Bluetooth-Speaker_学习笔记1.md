## M3: 电源系统（已学完 ✅）

### 核心元件

| 编号 | 元件 | 型号 | 封装 | 功能 |
|------|------|------|------|------|
| U5 | 充电IC | LGS4056HDA | SOP-8 | 278mA线性充电，4阶段(SC/TC/CC/CV) |
| U6 | 理想二极管 | CH213K | SOT-23-3 | USB通路防倒灌，30mΩ |
| U7 | 理想二极管 | LM66100DCKR | SC-70-5 | 电池通路开关，CE引脚控制，75mΩ |
| U1 | LDO | ME6211C33M5G-N | SOT-23-5 | 3.3V稳压，给AC6965A供电 |

### 关键设计参数

| 参数 | 值 | 公式/说明 |
|------|-----|----------|
| 充电电流 | 278mA | IBAT = 1000/RPROG = 1000/3600 |
| 涓流充电电流 | 27.8mA | 恒流的1/10 |
| 涓流转恒流阈值 | 2.9V | VBAT < 2.9V → 涓流 |
| 恒流转恒压阈值 | 4.2V | VBAT = 4.2V → 恒压 |
| 充电截止 | 电流降至27.8mA | 恒流的1/10 |
| CH213K压降 | 15mV@0.5A | 30mΩ导通电阻 |
| LM66100压降 | 37.5mV@0.5A | 75mΩ导通电阻 |
| LDO输出 | 3.3V | ME6211 |
| 阻尼电阻 | R22=1Ω | 抑制Type-C热插拔LC振铃 |
| LED限流 | R23/R24=10K | 0.3mA，低功耗优先 |

### 三种供电状态

```
状态1: USB供电 → CH213K→VCC-MCU→系统, LGS4056HDA→电池充电, LM66100关断
状态2: 电池供电 → LM66100→CH213K→VCC-MCU→系统
状态3: 边充边用 → USB→系统 + USB→电池充电, LM66100关断(电池不放电)
```

### LM66100 防反接原理

- 内部P-MOSFET + 比较器
- CE=USB 5V > VIN=电池3.7V → 比较器输出高 → P-MOSFET关断
- 电池反接时：VIN为负，比较器判断关断，体二极管反偏 → 双重保护

### CH213K vs 普通二极管

- 普通二极管压降0.3~0.5V → 电池放到3.9V系统就关机(浪费30%电量)
- CH213K压降15mV → 电池可放到3.5V → 多撑1~2小时
