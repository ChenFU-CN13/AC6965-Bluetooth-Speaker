## 三、SD卡接口电路深挖

### 3.1 核心元件

| 位号 | 参数 | 功能 |
|:---|:---|:---|
| U3 | HYCW13-TF09-205B | TF卡座，13引脚（9功能+4GND）|
| R7 | 2.2Ω | 电源串联限流，抑制热插拔浪涌 |
| R9 | 3.3kΩ | DAT0/CD 上拉 |
| C13 | 10μF | 电源滤波/储能 |
| 工作模式 | 1-bit SD | DAT1/DAT2悬空 |

### 3.2 R7 抑制浪涌电流原理

**浪涌来源**：TF卡内部有去耦电容（约4.7~10μF），插入瞬间从0V充电到3.3V，Δt极小（纳秒级），I = C×ΔV/Δt 瞬间暴增（>10A），会拉低VCC33总线导致主控复位。

**R7 限制**：
- 最大浪涌电流 I_max = VCC33/R7 = 3.3/2.2 ≈ 1.5A
- 充电时间常数 τ = R7×C = 2.2Ω×10μF = 22μs（平缓充电）
- 正常工作压降 = 0.1A×2.2Ω = 0.22V（可接受）

### 3.3 R7+C13 组成 RC 低通滤波器

- 截止频率 fc = 1/(2π×R7×C13) = 1/(2π×2.2×10μF) ≈ 7.2kHz
- 直流（0Hz）：R阻抗0，C阻抗∞ → 完全通过
- 高频噪声：被C短路到地 → 滤除
- 双向隔离：既保护VCC33不被TF卡拉崩，又保护TF卡不被总线噪声干扰

### 3.4 C13=10μF 选取逻辑（五个条件收敛）

1. **滤波**：fc=7.2kHz，刚好滤数字噪声（kHz~MHz级）
2. **储能**：100mA瞬态10μs，跌落ΔV=I×Δt/C=0.1V（仅3%）
3. **配合**：略大于TF卡内部电容（4.7μF），否则反充失去缓冲
4. **体积**：0603封装够用
5. **成本**：几分钱
6. **经验**：SD/TF卡电源的"行业标准值"

## 四、RC/LC 滤波器基础

### 4.1 截止频率公式（低通和高通共用）

```
fc = 1 / (2πRC)
```

**本质**：R阻抗 = C阻抗 时的频率点，输出衰减到0.707倍（-3dB）。

**决定高低通的是R和C的摆放位置，不是公式**：
- 低通：R串联+C并联到地 → 滤高频保低频
- 高通：C串联+R并联到地 → 滤低频保高频

### 4.2 RC vs LC 对比

| 维度 | RC | LC |
|:---|:---|:---|
| 组成 | 电阻+电容 | 电感+电容 |
| 能量损耗 | 有（电阻发热）| 几乎无 |
| 带载能力 | 弱（R压降随电流增大）| 强 |
| 滤波陡度 | 平缓 -20dB/十倍频 | 谐振处陡峭 |
| 成本/体积 | 便宜小 | 贵且占地方 |
| 典型应用 | 电源退耦、信号滤波 | DCDC输出、射频匹配 |

### 4.3 感抗公式

```
X_L = 2πfL
```
- L 是电感固有参数（常值，由匝数/磁芯决定）
- f 是变量（信号频率）
- X_L 随频率升高而增大（与电容相反）
- 直流时 f=0 → X_L=0（电感对直流相当于短路）

## 五、音频链路

### 5.1 两条输入路径

**MIC路径（麦克风→芯片）**：
```
驻极体麦GMI4015P → MIC(引脚8,PA2/PA0) → 内部PGA放大 → MUX → ADC → DSP
                    ↑
           MIC_BIAS(引脚7,PA3) 输出1.5~2V偏置电压给麦克风供电
           （驻极体麦内部JFET需要偏置才能工作）
```

**AUX路径（外部音源→芯片）**：
```
外部音源 → CN3(8脚PJ-393) → R17(10Ω) → C13(10μF) → AUXL(引脚6,PA4) → 内部MUX → ADC → DSP
                                  ↑              ↑
                              限流保护       隔直电容（高通滤波，挡DC偏置）
                              
CN3的DETECT → AUX_DET → MCU检测（插入时DETECT断开为高电平，MCU自动切换AUX模式）
```

### 5.2 DAC输出路径（芯片→功放）

```
DSP → DAC → DACL(引脚11) = VCOM(1.5V) + 音频交流信号
              │
              ↓
         C14(68nF) ← 隔直，挡住1.5V偏置
              │
              ↓
         R18(47kΩ) ← 输入电阻，设定功放增益
              │
              ↓
         LTK5128D IN-(引脚4) → BTL放大 → 喇叭
```

**VCOM（引脚10）= 1.5V**：DAC输出的直流中点（VDDIO 3.3V的一半），静默时DACL=1.5V，有声音时在1.5V上下波动。这就是为什么DAC输出需要隔直电容。

### 5.3 两个8脚连接器区分（已纠正）

| | CN1 | CN3 |
|:---|:---|:---|
| 型号 | PJ-393 8PJ | PJ-393 8PJ |
| 功能 | **耳机输出座** | **AUX输入座** |
| 信号方向 | DACL/DACR **从芯片出来**→耳机 | 外部音源→AUXL/AUXR **进入芯片** |
| DETECT | 悬空（未用） | → AUX_DET → MCU检测 |
| 路径元件 | R12(10Ω)+C10(10μF) / R13(10Ω)+C11(10μF) | R17(10Ω)+C13(10μF) / R19(10Ω)+C15(10μF) |

> **纠正记录**：C14(68nF)+R18(47kΩ) 属于 **DACL→功放** 路径，不是AUXL路径。AUXL路径只有R17+C13。

## 六、LTK5128D 功放芯片

### 6.1 定位

AC6965A的DAC输出仅毫伏级，LTK5128D是中间的"肌肉"，把微弱信号放大到能推喇叭的瓦级。

### 6.2 引脚功能（ESOP-8）

| 引脚 | 名称 | 本项目连接 | 功能 |
|:---|:---|:---|:---|
| 1 | SD | R14(1kΩ)←MUTE, R15(100kΩ)上拉VCC-MCU | 使能：高=关断，低=开启 |
| 2 | BYPASS | C12(1μF)→GND | 内部参考电压旁路，决定开机时间和POP声 |
| 3 | MODE | **R16(10kΩ)上拉到VCC-MCU** | 模式选择：高=D类，低/悬空=AB类 |
| 4 | IN- | C14(68nF)+R18(47kΩ) ← DACL | 反相音频输入 |
| 5 | OUTN | → CN2 Pin1 → 喇叭负极 | BTL输出负端 |
| 6 | VDD | VCC-MCU + C17(10μF)退耦 | 电源3~6.5V |
| 7 | GND | GND | 地 |
| 8 | OUTP | → CN2 Pin2 → 喇叭正极 | BTL输出正端 |
| 9 | EP | GND | 散热焊盘，需大面积铺铜 |

### 6.3 BTL桥接输出原理

```
普通单端：信号→放大→OUT→喇叭→GND，电压摆幅0~VDD
BTL：信号→放大→OUTP→喇叭→OUTN←反相放大，电压摆幅0~2×VDD，功率翻4倍

静音时：OUTP=VDD/2, OUTN=VDD/2，喇叭两端压差=0
有信号时：OUTP=VDD/2+Vsig, OUTN=VDD/2-Vsig，压差=2×Vsig
```

### 6.4 增益计算

```
Av = 2 × Rf / (Rin + Rs) = 2 × 180kΩ / (47kΩ + 7kΩ) = 360/54 ≈ 6.67倍 ≈ 16.5dB

Rf=180kΩ（内部反馈电阻），Rs=7kΩ（内部串联电阻），Rin=47kΩ（外接R18）
```

### 6.5 D类 vs AB类（已纠正）

> **重大纠正**：本项目 MODE 通过 R16 上拉到 VCC-MCU = 高电平 = **D类模式**（不是AB类）

| 特性 | D类（本项目）| AB类 |
|:---|:---|:---|
| 效率 | ~90% | ~60% |
| 静态电流 | 5mA | 8mA |
| 失真 | 中等 | 低（0.065%）|
| EMI | 高（520kHz开关）| 低 |
| 输出滤波器 | 需要LC | 不需要 |
| 适用 | 电池供电、大功率 | 高保真、对EMI敏感 |

**选D类原因（推测）**：蓝牙音箱对续航敏感；40mm小板喇叭走线短EMI可控；D类4.2V能输出2.2W。

### 6.6 外围元件清单

| 位号 | 参数 | 作用 |
|:---|:---|:---|
| C14/C16 | 68nF | 隔直耦合（高通），fc≈43Hz（与54kΩ组合）|
| R18/R20 | 47kΩ | 输入电阻，设定增益6.67倍 |
| C12 | 1μF | BYPASS旁路，决定开机时间174ms，抑制POP声 |
| R14 | 1kΩ | SD引脚限流 |
| R15 | 100kΩ | SD上拉（MCU未初始化时功放关断防POP）|
| R16 | 10kΩ | MODE上拉→D类模式 |
| C17 | 10μF | VDD退耦 |

### 6.7 MUTE控制逻辑

| MUTE电平 | SD状态 | 功放状态 |
|:---|:---|:---|
| 高（VCC-MCU）| 高 | 关断（静音）|
| 低（0V）| 低 | 正常工作 |
| 悬空 | 高（R15上拉）| 关断（上电默认静音防POP）|

## 七、3W/4Ω 喇叭概念

### 7.1 参数含义

- **3W** = 额定功率（能承受的最大长期功率），相当于电脑扬声器级别，40mm小盒内已经很响
- **4Ω** = 交流阻抗（1kHz时测量），直流电阻DCR约3~3.5Ω

### 7.2 为什么选4Ω不选8Ω

```
P = V²/R，BTL输出VDD=4.2V：
  4Ω：P=4.2²/4=4.41W（理论），实际2.2W@THD10%
  8Ω：P=4.2²/8=2.2W（理论），实际更小
阻抗越小同样电压下功率越大，小音箱要够响选4Ω合理。
```

### 7.3 选型要点

阻抗必须和功放设计匹配（不匹配→功率异常或过热）；功率不要超过功放最大输出；尺寸受40×40mm PCB限制。

## 八、射频天线基础（M6 入门）

### 8.1 50Ω阻抗概念

不是"有一个50Ω电阻"，而是"PCB走线本身的特性阻抗=50Ω"。50Ω是功率和衰减的历史最佳平衡点，蓝牙芯片BT_RF引脚、天线、走线三者必须都50Ω，信号传输效率最高。

### 8.2 共面波导（CPW）

```
信号线和GND在同一层，旁边就是地铜皮：
  GND │ 信号线 │ GND   ← 全在顶层
  
三个参数控制阻抗：
  W（线宽）↑ → 阻抗↓
  S（间距）↑ → 阻抗↑
  H（板厚）↑ → 阻抗↑
  
原理图标注"50ohm共面单端阻抗"= BT_RF→C3→U10走线用共面波导设计，控制50Ω
"单端" = 一根信号线（不是差分两根）
```

### 8.3 π型匹配网络

```
BT_RF ──[C3:2.7pF]──┬── L1(10μH) ── GND
                      │
                      ├──→ U10天线
                      │
                      └── L2(10μH) ── GND

原理：实际PCB天线阻抗几乎不可能完美50Ω，C3/L1/L2是"过渡带"让信号平缓过渡。
"可自行调整匹配电路" = 实际值是参考，做出来后用网络分析仪测S11调。
```

### 8.4 复刻策略

**射频部分照抄原版PCB布局，不要自己改走线宽度和间距。** 匹配元件值（C3=2.7pF, L1/L2=10μH）先用原值，有仪器后再调。
