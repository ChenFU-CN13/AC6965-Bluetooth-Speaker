# 焊接记录 — Mini Bluetooth Speaker (AC6965A)

> 项目：基于 AC6965A 的便携式蓝牙音箱（原理图/PCB 抄画复刻）
> 记录范围：物料采购 → 焊接 → 上电调试
> 焊接方式：**锡膏 + 加热台 + 热风枪（全程未使用烙铁，无钢网）**

---

## 一、焊接工艺与工具

### 1.1 使用的工具

| 工具 | 用途 |
|:---|:---|
| 加热台 | 0402 阻容批量回流（板级预热） |
| 热风枪 | IC 芯片（QSSOP24 / ESOP-8）、接口座焊接 |
| 锡膏 + 注射器（细针头） | 无钢网条件下的焊盘上锡 |
| 镊子 | 0402 元件贴装 |
| 万用表 | 通断 / 电压 / 对地电阻测量 |
| 洗板水 + 毛刷 | 焊后清洗助焊剂残留 |

### 1.2 无钢网的替代方案

本板未开钢网，采用**针头点涂锡膏**代替刮锡膏：

- 锡膏回温 15~30 分钟后搅匀，装入注射器 + 细针头
- 逐个焊盘点涂，每个焊盘只挤针尖大小的量
- 0402 焊盘两端锡膏量尽量一致，防止回流时立碑
- IC 引脚焊盘沿引脚方向涂一条薄线，回流时锡膏自动分配

> 结论：可行但效率低、锡量难控，下一块板建议开 0.12mm 电抛光钢网。

### 1.3 焊接顺序（分 4 批，每批焊完先测电压）

| 批次 | 模块 | 焊接内容 | 验证判据 |
|:---|:---|:---|:---|
| 1 | 电源模块 | 充电 IC、电源切换、LDO、大电容 | VCC-5V=5V、VCC33=3.3V、VBAT≈4.2V |
| 2 | 主控模块 | AC6965A、晶振、去耦电容 | 3.3V 正常、晶振起振、无异常发热 |
| 3 | 音频模块 | LTK5128D 功放、音频耦合元件 | 功放 VDD、SD 引脚高电平、BTL 输出 VDD/2 |
| 4 | 射频/接口 | 匹配网络、天线、各接口座 | 蓝牙可被搜到、可连接播放 |

## 二、遇到的问题与解决（按发生顺序）

### 问题 1：LGS4056HDA 充电芯片烧毁

**现象**
- 电源模块焊完首次上电，各路电压测量正常
- 测量过程中万用表两根探针**误触到相邻的其他测试引脚**
- 之后指示灯完全不亮，所有输出电压消失
- 拆下芯片前触摸芯片明显**发烫**；拆下后不再发烫

**原因分析**
- 探针误触 = 用探针把两个不同电位的网络**瞬间短接**，本质是一次意外短路
- 危险组合：VCC-USB5V(5V) 碰 VCC33(3.3V)、VBAT(4.2V) 碰 VCC33、5V 碰 GND
- 芯片持续发烫 → 内部击穿形成对地短路，电流经芯片直通地放热
- 拆下后不烫 → 板上无其他元件对地短路，**故障局限于该芯片本身**

**解决**
- 更换新的 LGS4056HDA
- 换件前先断电测各电源网络对地电阻，以及焊盘通断，确认 PCB 没有连带损伤
- 新芯片一次性焊到位，避免反复拆焊

**结论/教训**
- 上电测量时探针必须**单点接触**，两只探针不要同时靠近密集测试点
- 芯片发烫是内部短路的直接证据，**发烫必须立即断电**，不能"再看看"

---

### 问题 2：同一颗芯片反复热风枪拆焊

**背景**
- LGS4056HDA 为 ESOP-8 带底部散热焊盘封装，因排查问题来回拆焊多次

**风险认识**
- ESOP-8 底部散热焊盘依靠树脂与 PCB 铜箔粘合，反复高温加热会让树脂失效
- 拆焊超过 3 次，焊盘脱落、走线断裂的概率显著上升
- 散热焊盘一旦脱落，芯片散热能力下降，还可能导致虚焊

**应对**
- 拆件后用万用表蜂鸣档逐脚验证焊盘与对应网络的连通性：
  - VCC 焊盘 ↔ USB VBUS 引脚
  - BAT 焊盘 ↔ 电池座正极
  - 散热焊盘 ↔ GND
  - PROG 焊盘 ↔ PROG 电阻另一端
- 四项全通才允许焊新芯片；不通则飞线修补或重打板

> 结论：**带散热焊盘的 IC 不允许反复试拆**。先测清楚再动手，一次焊到位。

### 问题 3：VBAT 电压异常（0.x V / 1.1 V），洗板后恢复正常

**现象**
- 全部元件焊完，Type-C 输入 5V，不接电池
- 测 VBAT 引脚，读数只有 **0.x V 和 1.1 V**，远低于预期
- 指示灯不亮，充电路径表现为不工作

**排查过程**
1. 测充电 IC 的 VCC 引脚是否有 5V（确认输入到芯片）
2. 测 CE（使能）引脚电平是否被拉低
3. 测 PROG 引脚电压是否正常（不能为 0V 或悬空）
4. 测 BAT 引脚对地电阻，排除新款芯片再次击穿

**根本原因**
- **助焊剂/松香残留造成漏电与局部微短路**，干扰了芯片的正常工作点
- 属于典型的"幽灵故障"：元件和焊接都没问题，但板面不干净

**解决**
- 用洗板水 + 毛刷彻底清洗板面，吹干后重新上电
- VBAT 恢复正常，充电回路工作正常

**结论/教训**
- **焊完必须洗板**，助焊剂残留是调试期最常见的虚假故障源
- 遇到"电压不对但元件全对"的情况，先洗板再排查电路

### 问题 4：10Ω 电阻漏买（音频耦合电阻）

**现象**
- 音频部分需要 4 颗 10Ω 电阻，采购时遗漏
- 手头 0402 电阻最小只有 220Ω，另有 1Ω 电阻

**电路位置与作用**

| 位号 | 路径 | 作用 | 负载阻抗 |
|:---|:---|:---|:---|
| R12 / R13 | DACL/DACR → 耳机座（CN1） | 与 10μF 电容串联，隔直 + 限流 + 轻度阻抗匹配 | 16~32Ω（耳机） |
| R17 / R19 | AUX 座（CN3） → AUXL/AUXR | 同上 | >10kΩ（主控 ADC 输入） |

**替代方案分析**

- 用 **220Ω** 替代：
  - AUX 输入端（R17/R19）负载 >10kΩ，分压损失约 2%，可用
  - 耳机输出端（R12/R13）负载仅 16~32Ω，形成严重分压，耳机仅得约 13% 信号（约 -18dB），**音量暴降，不可用**
- 用 **1Ω** 替代：
  - 耳机端分得约 97% 信号，音量略高于原设计
  - AUX 端信号损失可忽略
  - 唯一代价是限流保护能力变弱，对正常耳机使用无影响

**最终处理**
- 四颗全部用 **1Ω** 替代 10Ω，功能正常

### 问题 5：TF 卡座供电电阻 2.2Ω 缺料

**电路位置**
```
VCC33 → R9(2.2Ω) → TF 卡 VDD（U3 第 4 脚）
                 └─ C9(10μF) → GND
```

**作用**
- 抑制 TF 卡热插拔浪涌电流
- 与 C9 组成 RC 低通，隔离 TF 卡高速切换噪声回灌主电源

**用 1Ω 替代的影响对比**

| 参数 | 原设计 2.2Ω | 1Ω 替代 | 评价 |
|:---|:---|:---|:---|
| 浪涌限流 | 约 1.5A | 约 3.3A | 限流变弱，仍有限流作用 |
| RC 截止频率 | 约 7.2kHz | 约 15.9kHz | 高频噪声衰减略降，仍充足 |
| 稳态压降 | 约 220mV | 约 100mV | **更小，TF 卡供电更接近 3.3V** |

**最终处理**
- 用 1Ω 替代 2.2Ω，TF 卡播放功能正常

### 问题 6：万用表蜂鸣档判断通断的误区

**现象**
- 用蜂鸣档判断焊盘是否连通时，隔着 1Ω 电阻也会响，容易误判为短路

**原理**
- 蜂鸣档的导通阈值一般为 30~70Ω（不同型号有差异）
- 1Ω 远低于阈值 → 一定响
- 本板 USB 5V 输入路径上串有 1Ω 电阻，测 VCC 焊盘与 USB VBUS 时蜂鸣属正常
- 判断**对地短路**必须用**电阻档读具体数值**，不能只看蜂鸣

> 结论：蜂鸣档判"通"，电阻档判"短"。正常 VCC/BAT 焊盘对地应在 10kΩ 以上。

## 四、关键经验教训

1. **上电测量防短接**：探针单点接触，密集测试点区域尤其要小心，一次误触可能烧掉整颗芯片。
2. **芯片发烫立即断电**：发烫等于内部短路，继续通电只会扩大损伤。
3. **带散热焊盘的 IC 不准反复拆焊**：超过 3 次焊盘极易脱落，宁可先测清楚再一次焊到位。
4. **焊完必须洗板**：助焊剂残留会导致漏电、电压异常等"幽灵故障"，本次 VBAT 异常即由此引起。
5. **蜂鸣档判通、电阻档判短**：低阻值电阻（1Ω/2.2Ω/10Ω）在蜂鸣档一定会响，不能据此判断短路。
6. **电阻替代要看负载阻抗**：串联电阻的替换必须结合后级负载算分压。低阻负载（耳机 32Ω）对串联阻值敏感，高阻负载（ADC >10kΩ）几乎不敏感。
7. **分阶段上电**：每焊完一个模块先测电压再往下焊，避免电源有问题时连带烧毁后级芯片。
